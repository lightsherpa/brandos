# Bundled fallback font

Instrument Sans regular variable font, unmodified, from the Google Fonts repository:

- Source directory: https://github.com/google/fonts/tree/main/ofl/instrumentsans
- Original filename: `InstrumentSans[wdth,wght].ttf`
- Local filename: `instrument-sans.ttf`
- Licence: `OFL-InstrumentSans.txt` (SIL Open Font License 1.1).

The same unmodified font and licence are included in `public/caastor/assets/fonts/` for the flagged browser specimen. This fallback is not automatically stored as the brand's display font and cannot satisfy a missing foundation field.
