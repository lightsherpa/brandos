# Discovery intake — Refero research and implementation

Brief: web source intake for brand owners; gather existing brand sources and desired-direction references, then engine-generated BIO review. Direct build within Caastor's established Plex/mineral/graphite/cobalt system, without Inter or decorative headline word changes. User screenshot identifies repetitive dropdowns, long upload cards and loose information hierarchy.

Research via live Refero MCP: three style searches; full Cron Calendar, Linear and Workflow styles; full Sana, Delphi and Teal intake screens; full Spyglass brand-profile flow. Sana screenshot visually inspected. Dominant build target is existing Caastor design system. Workflow supplies neutral surface separation and hairline structure; Cron contributes compact action geometry only. Linear dark theme and Inter are rejected, retaining only its interface density as a comparison. No copying a marketing page into onboarding.

| Decision | Evidence | Role and adaptation |
|---|---|---|
| Light workspace, single bordered intake surface | Workflow full style; existing Caastor tokens | Structural separation with thin borders, no nested card pile |
| Plex functional headline and UI | User's explicit no-Inter preference; existing Caastor registry | Remove Georgia italic and highlighted phrase; preserve platform fonts |
| Website first, references next, optional files last | Sana intake; Spyglass flow 13471 | Prioritize sources over manual brand questions |
| Compact URL rows and per-source purpose | Delphi upload screen; product aspiration separation requirement | Secondary remove action; expandable intent note |
| Optional document disclosure and compact file lists | Teal input-method choice; Delphi list | Keep bucket/purpose data intact, expose browse and drag targets without giant dashed boxes |
| Source count and output summary | User's engine-generated BIO proposition | Reflect actual entered sources; no fake coverage or progress |
| Cobalt actions and focus only | Existing Caastor tokens and user constraint | Do not import Cron orange or Linear lime into platform |
