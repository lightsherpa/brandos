# docs/brandos: index

- `harness/`: how BrandOS works as a harness. OVERVIEW.md is the architecture; it also holds the agent contracts, the check registry, the planner, the loop, the router design.
- `specs/`: product specs (demo flow and UX, wireframes, Frontify-for-SMB, the model plan). [ROADMAP.md](specs/ROADMAP.md) is the post-VDS backlog.
- `handoffs/`: one folder per task for Claude/Codex, dated. Each has a PROMPT or brief file to start from.
- `research/`: teardowns and reviews.

Rule: new handoffs go in `handoffs/YYYY-MM-DD-topic/`. Nothing lives outside this folder.
